Elaichi provides a single MCP endpoint that unifies access to multiple AI models such as Claude, ChatGPT, Cursor, and Microsoft Copilot. It ensures each user’s AI interactions are permission‑controlled and fully logged, offering enterprises granular oversight and compliance. The platform emphasizes security, privacy, and easy integration across applications, positioning itself as a centralized gateway for AI services.

**Areas:** AI · Integration · Security · Compliance · Platform · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Elaichi: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
